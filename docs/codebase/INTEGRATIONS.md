# Интеграции

## Сервисы

| Сервис | Роль | Доступ | Важность |
| --- | --- | --- | --- |
| Railway | Хостинг Go-сервера и тома с пользовательскими днями | Публичный HTTPS, операции с личными записями требуют сессии | Рабочая версия. [Конфигурация](../../railway.toml) · [Деплой](../deploy-for-frontend.md) |
| Anthropic | Предложение фоновых звуков по уменьшенной обложке | Серверный `ANTHROPIC_API_KEY` | Опционально. [Клиент распознавания](../../backend/internal/vision/vision.go) · [Маршрут](../../backend/internal/httpapi/ambience.go) |
| Supabase | Альтернативный режим с Auth, Postgres и Storage | Публичный ключ в браузере, доступ по токену пользователя и RLS | Альтернативная конфигурация. [Адаптер](../../web/cloud-diary.mjs) · [Политики](../../supabase/migrations/) |
| Vercel | Альтернативный хостинг статики и конфигурации | Публичный HTTPS, параметры через переменные окружения | Альтернативная конфигурация. [Маршрут](../../api/runtime.mjs) · [Конфигурация](../../vercel.json) |

Прочитанный публичный ответ `GET /api/runtime` на рабочей версии 22.11.2026 содержит `mode: "local"`, `analytics: "local"`, `profile: true`, `share: true`. В этой проверке флаг распознавания обложки отсутствовал, поэтому доступный путь подбора звуков использует локальные правила. [Публичная конфигурация](https://throughthelense-production.up.railway.app/api/runtime) · [Правила выбора](../../web/ambience.mjs)

## Хранилища

| Данные | Хранилище и доступ | Ограничение |
| --- | --- | --- |
| Гостевые дни и черновики | IndexedDB через [`journal.mjs`](../../web/journal.mjs) | Данные зависят от браузера и устройства |
| Пользователи, сессии, сводки, ссылки и общий счётчик посещений | SQLite через [`store`](../../backend/internal/store/) | Go-развёртывание рассчитано на один подключённый том |
| Полная копия дня аккаунта | Файлы в `DATA_DIR/copies` через [`copies`](../../backend/internal/copies/) | Строка SQLite должна указывать на опубликованную ревизию файла |
| Дни в альтернативном режиме | Таблица и закрытый бакет Supabase через [`cloud-diary.mjs`](../../web/cloud-diary.mjs) | Крупные копии загружаются частями |

## Ключи и сессии

Go читает ключ Anthropic из окружения. В браузерную конфигурацию Supabase передаётся только ключ с префиксом `sb_publishable_`. HTTP-режим использует cookie сессии `ttl_session`. ## Поведение при сбое

В клиенте подбора звуков ограничено время запроса. При недоступности сервиса используются слова записи и яркость обложки. SDK Anthropic настроен без клиентских повторов. Go отдельно задаёт тайм-ауты HTTP-сервера и завершения процесса. Railway проверяет `/api/runtime` и перезапускает сервис при ошибке. [Фронтенд](../../web/ambience.mjs) · [Клиент Anthropic](../../backend/internal/vision/vision.go) · [HTTP-сервер](../../backend/cmd/server/main.go) · [Railway](../../railway.toml)

## Наблюдаемость

Go пишет журнал ошибок и уборки файлов. После согласия браузер отправляет событие просмотра главной для общего суточного счётчика, а альтернативная конфигурация может загружать Vercel Analytics.
