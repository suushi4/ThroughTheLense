# Соглашения в коде

## Именование

| Объект | Соглашение | Пример |
| --- | --- | --- |
| Файлы фронтенда | Имена с дефисами для составных названий | [`day-folder.mjs`](../../web/day-folder.mjs), [`home-lab.mjs`](../../web/home-lab.mjs) |
| Функции JS | `camelCase`, глагол для операции | `saveDay` в [`diary.mjs`](../../web/diary.mjs), `mountPlayer` в [`player.mjs`](../../web/player.mjs) |
| Идентификаторы Go | Экспортируемые имена начинаются с прописной, внутренние со строчной | `Config` и `env` в [`config.go`](../../backend/internal/config/config.go) |
| Переменные окружения | Прописные буквы с подчёркиваниями | `PUBLIC_BASE_URL`, `DATA_DIR` в [`config.go`](../../backend/internal/config/config.go) |

## Форматирование и проверки

Для Go используется стандартный `gofmt`. Перед изменением Go стоит проверить код через `go vet ./...` из `backend/`. Проверка статики вызывается командой `node scripts/check-dist.mjs` после сборки и проверяет синтаксис JS, обязательные файлы и локальные ссылки. Порог форматирования JS отдельным npm-скриптом не задан. [Команды](../../package.json) · [Проверка сборки](../../scripts/check-dist.mjs) · [Инструкция передачи](../deploy-for-frontend.md)

## Импорты и модули

Приложение импортирует браузерные модули по относительным путям с расширением `.mjs` и использует именованные экспорты. В коде эффекта сцены встречаются пакетные импорты, которые обрабатывает сборка. Go использует полные пути пакетов внутри модуля `throughthelense/backend`. [ES-модули](../../web/app.mjs) · [Эффект сцены](../../web/scene-effects.jsx) · [Сборка эффекта](../../scripts/build-visuals.mjs) · [Go-модуль](../../backend/go.mod)

## Ошибки и журнал

- Фронтенд сообщает об ошибках рядом с полями или через сообщения состояния. Общие ошибки проверки материалов выбрасываются из функций сцены и отображаются редактором. [Проверка материалов](../../web/scene.mjs) · [Интерфейс ошибок](../../web/app.mjs)
- HTTP API возвращает статус и объект `{message}`. Серверный журнал на стандартном пакете Go `log` фиксирует запуск, ошибки с HTTP-методом и путём и результат уборки файлов. [HTTP-ошибки](../../backend/internal/httpapi/server.go) · [Запуск и уборка](../../backend/cmd/server/main.go)
- Имена переменных для ключей заданы в конфигурации. Опциональный сервис анализа фото получает уменьшенный снимок и возвращает только теги. [Конфигурация](../../backend/internal/config/config.go) · [Контракт анализа](../backend-integration.md)

## Соглашения в тестах

Корневые JS-тесты имеют суффикс `.test.mjs`, сценарии Playwright лежат в `tests/` как `.cjs`, а Go-тесты `*_test.go` рядом с проверяемым пакетом. Сторонние ответы в браузерных тестах подменяются через маршруты Playwright, для анализа фото на Go используется `httptest`. [Тест сцены](../../scene.test.mjs) · [Тест фоновых звуков](../../tests/ambience.cjs) · [Тест Go](../../backend/internal/httpapi/ambience_test.go)
