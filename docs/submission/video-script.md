# Сценарий видео (до 3:00)

Сайт: `https://throughthelense-production.up.railway.app` (ниже — **сайт**). Целевая длина 2:55, запас 5 секунд. Сцена дня длится до 12 секунд, поэтому в первом кадре она играет целиком, дальше показываются только нужные моменты.

## Подготовка (до записи)

- В основном окне браузера войти в **аккаунт для показа**. Адрес должен быть на настоящем домене, **не `@example.org`**: перед записью тестовые аккаунты удаляются (`scripts/purge-test-users.sh --apply`).
- Заранее сохранить в этом аккаунте дни из [results.md](results.md): хотя бы «Домой без спешки», «Какао у остановки», «Свет после репетиции» и один свой день.
- Для кадра 4 приготовить на рабочем столе материалы нового дня: фото, текст и трек (свой или со свободной лицензией).
- Второе окно в режиме инкогнито (без входа) понадобится для открытия ссылки в кадре 7.
- Окно 1440×900, масштаб 100%, звук включён, системное «уменьшение движения» выключено, панели разработчика закрыты. Запись: OBS, Win+Alt+R или Cmd+Shift+5, со звуком системы.
- Шаг «Поделиться» работает после мержа PR #7. Проверить его на сайте до записи.

## Если что-то пошло не так во время записи

- **Трек долго готовится в кадре 5.** Перед записью один раз нажать «Сравнить другую песню», чтобы второй трек закэшировался.
- **Сайт не отвечает.** Записать с локального сервера (`npm run build`, затем `cd backend && WEB_DIR=../dist go run ./cmd/server`, адрес `http://127.0.0.1:8080`). В видео показать живой адрес отдельно.
- **Видео длиннее 3:00.** Первым сокращать кадр 6: оставить один день вместо двух.
