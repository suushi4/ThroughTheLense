| Инструмент | Для чего | Источник |

## Бэкенд и развёртывание

| Инструмент | Для чего |
| --- | --- |
| Go 1.27 (стандартная библиотека `net/http`) | Сервер сайта и API |
| SQLite через `modernc.org/sqlite` (без CGO) | Аккаунты, сессии, список дней, публичные ссылки |
| argon2id (`golang.org/x/crypto/argon2`) | Хеширование паролей |
| Docker (многоэтапная сборка, `distroless/static`) | Образ: сборка `dist/` на Node 22 и статический Go-бинарь |
| Railway | Хостинг, постоянный том для базы, автодеплой из `main` |
| GitHub | Репозиторий, pull request и ревью, источник автодеплоя |
| Python 3 (`serve.py`) | Локальный сервер для разработки |
| Vercel, Supabase Auth и Storage | Альтернативная конфигурация в `vercel.json`, `api/runtime.mjs`, `web/cloud-diary.mjs` и `supabase/migrations`. Подтверждённый публичный деплой работает на Railway |

## Музыка, звуки места и экспорт

- Встроенная музыка включает записи CC0 из Wikimedia Commons и оригинальные инструментальные фрагменты, синтезированные для ThroughTheLense. Подборка фоновых шумов включает полевые записи CC0 и четыре синтезированных звука. [Источники музыки](../music-licenses.md), [источники звуков](../ambience-licenses.md).
- Браузер предлагает фон по словам записи и яркости обложки. Сервер умеет подключать Anthropic для подбора по фотографии, когда в `/api/runtime` указан режим `ambience: "vision"`. [Контракт и настройки](../backend-integration.md).
- Монтаж сцены, экспорт ZIP и обрезка PCM WAV выполняются в браузере. FFmpeg использован для подготовки встроенных аудиофайлов. [Обработка музыки](../music-licenses.md), [обработка фоновых звуков](../ambience-licenses.md).
