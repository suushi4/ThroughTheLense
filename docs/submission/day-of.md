# День сдачи, 22.11: всё по шагам

Цель — всё отправить к **20:00**, дедлайн 23:59 по Астане. Сайт: <https://throughthelense-production.up.railway.app>.

## 1. Очистка базы (≈ 5 минут, WSL, из корня проекта)

```sh
cd ~/ThroughTheLense && git pull
railway whoami                         # если не залогинен: railway login --browserless
scripts/purge-test-users.sh            # пробный запуск: в логе список @example.org, ничего не удаляется
scripts/purge-test-users.sh --apply    # удаление тестовых аккаунтов и их дней
```

Скрипт дважды передеплоит сервис, каждый раз сайт недоступен около минуты. После этого откройте сайт и убедитесь, что главная работает.

## 2. Демо-аккаунт (≈ 2 минуты, Windows, обычное окно Chrome)

Сайт → «Войти» → «Создать аккаунт» → **ваша настоящая почта** и пароль от 8 символов. Не используйте `@example.org`: такие аккаунты удаляет очистка.

## 3. Дни (≈ 40 минут)

Все дни создаются в демо-аккаунте. После каждого: «Сохранить день», затем F5 и проверка, что день открывается из архива.

| Папка | Как создать | Файлы |
| --- | --- | --- |
| `01-domoy-bez-speshki` | Открыть сайт`/journal.html?example=demo-street#new` → «Взять материалы «Домой без спешки»» → «Посмотреть сцену» → «Сохранить день» | Не нужны: материалы примера |
| `02-kakao-u-ostanovki` | То же с `?example=demo-cocoa` | Не нужны |
| `03-svet-posle-repeticii` | То же с `?example=demo-stage` | Не нужны |
| `04-<ваш-день>` | «Записать день» → свои файлы → «Посмотреть сцену» → выбрать фразу и обложку → «Сохранить день» | 1–5 фото JPEG, PNG или WebP до 8 МиБ (свои). 3–6 предложений о дне, хотя бы одно с конкретной деталью: что услышали, почувствовали, заметили впервые. Трек MP3 или WAV на 3–60 секунд до 12 МиБ: свой или со свободной лицензией, источник записать |
| `05-odin-kadr-dva-ritma` | В предпросмотре дня 04: «Сравнить другую песню» → «Поставить «…»». Записать сцену с обоими треками | Те же, что у 04 |

Минимум для сдачи — 01–04. Подробно о папках: [results.md](results.md).

## 4. Запись экрана со звуком (Windows)

Браузер: Chrome на весь экран (F11) на мониторе 1920×1080, масштаб страницы 100%, звук системы включён, в Windows выключены уведомления («Не беспокоить»). Чтобы не было обрывов, второй трек для кадра 5 сценария прогрейте заранее: один раз нажмите «Сравнить другую песню».

**Вариант A: OBS Studio (рекомендуется).**
1. Настройки → Видео: базовое и выходное разрешение **1920×1080**, FPS **30**.
2. Настройки → Вывод → Запись: формат **mp4** (или mkv, потом «Файл → Ремультиплексировать»), кодировщик аппаратный (NVENC / QuickSync / AMF) или x264, качество «Высокое».
3. Настройки → Аудио: «Звук рабочего стола» — устройство по умолчанию. Микрофон — включить, если озвучиваете вживую, иначе выключить.
4. Источник: «Захват экрана» (захват окна Chrome иногда даёт чёрный экран). Проверьте индикатор звука рабочего стола: при воспроизведении сцены он должен шевелиться.
5. «Начать запись» → сценарий → «Остановить запись». Файл появится в папке «Видео».

**Вариант B: Win+Alt+R (Xbox Game Bar).**
1. Параметры → Игры → Записи: «Записывать звук во время записи игры» — включить, качество видео «Высокое», 30 кадров/с.
2. Сделайте окно Chrome активным, нажмите **Win+Alt+R**, по окончании ещё раз **Win+Alt+R**. Файл появится в «Видео\Записи».
3. Ограничения: пишется только одно активное окно (переключение на окно инкогнито для кадра 7 не попадёт в ту же запись), разрешение равно размеру окна. Для сценария с двумя окнами лучше OBS.

Видео записывается по [video-script.md](video-script.md): 2:55, текст за кадром там же. Сцены дней для папок результатов записываются отдельно, каждая по 12 секунд.

## 6. Что и куда загрузить

Требования брифа: рабочий прототип, видео до 3 минут, 3–7 результатов, описание до 1 страницы, художественные приёмы, подтверждение вклада, перечень инструментов. Форму или площадку загрузки указывают организаторы. Проверьте её в брифе или канале хакатона, в репозитории этой информации нет.

| Что | Как отдать |
| --- | --- |
| Прототип | Ссылка на сайт |
| Видео | Файл, если форма принимает. Иначе YouTube (доступ «по ссылке») или Google Drive («все, у кого есть ссылка») |
| Результаты | Папка `результаты/` архивом или ссылкой на Google Drive с открытым доступом |
| Описание, приёмы, инструменты | PDF из папки выше |
| Подтверждение вклада | Ссылка на репозиторий (публичный) и абзац «Команда» из описания |

Перед отправкой откройте каждую ссылку в окне инкогнито: сайт, видео, папку результатов, репозиторий.
