# ThroughTheLense

Личный фотодневник для Genesis Hackathon. Запись дня превращается в сцену: выбранный снимок, дословная фраза на музыкальном акценте и возвращение к тому же снимку.

На главной работают три примера, плеер, сравнение треков и полка гостевых записей. В дневнике можно подготовить и отредактировать сцену, сохранить её, найти в архиве и перенести файл дня через экспорт и импорт.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `/` · `web/index.html`, `web/home*.mjs`, `web/home*.css` | Главная, демонстрационные сцены, сравнение музыки и гостевая полка |
| `/journal.html` · `web/app.mjs`, `web/styles.css` | Архив `#archive`, редактор `#new` и `#edit/<id>`, предпросмотр `#preview`, сохранённый день `#day/<id>` |
| `/account.html` · `web/account-page.mjs`, `web/account.mjs` | Экран входа и клиентские операции аккаунта |
| `web/scene.mjs`, `web/player.mjs`, `web/demo.mjs` | Подготовка сцены, воспроизведение, материалы примеров |
| `web/diary.mjs`, `web/cloud-diary.mjs`, `web/journal.mjs`, `web/transfer.mjs` | Адаптер дневника, облачное хранилище, IndexedDB и формат копии дня |
| `serve.py`, `account_server.py`, `api/runtime.mjs`, `supabase/migrations/` | Локальный сервер и SQLite, конфигурация среды, миграции Supabase |
| `backend/` · `cmd/server`, `internal/httpapi`, `internal/store`, `internal/copies` | Go-сервер с тем же API: статика из `dist/`, аккаунты, дни в SQLite и файлах копий |

Ссылка `/journal.html?example=demo-cocoa#new` предлагает выбранный пример. Материалы загружаются по кнопке, а замена заполненного черновика требует подтверждения. `/journal.html?mode=guest#archive` открывает записи этого браузера, даже когда в аккаунте есть активная сессия.

## Подключение бэкенда

- Команда фронтенда отвечает за HTML, стили, редактор, плеер и состояния интерфейса. Для подключения нового бэкенда начните с адаптеров `web/account.mjs` и `web/diary.mjs`, где интерфейс получает сессию и вызывает операции с днями.
- Сохраните поведение гостевого архива и черновиков. Главная читает гостевой IndexedDB через `web/home-shelf.mjs`, а записи в аккаунте проходят через выбранный адаптер хранилища.
- Полная копия дня использует формат `ThroughTheLense/day` версии 1. При изменении хранения сохраните чтение старых копий. Секреты задаются на сервере через переменные окружения. В репозиторий включается только конфигурация без значений секретов.
- Go-сервер в `backend/` повторяет HTTP-контракт `account_server.py`, поэтому `web/account.mjs` и `web/diary.mjs` работают с ним без изменений. Новые маршруты добавляйте в оба сервера или явно отмечайте как только Go. Развёртывание описано в README (`Dockerfile`, `fly.toml`).
- Формат данных, варианты запуска и сценарии проверки описаны в [docs/backend-integration.md](docs/backend-integration.md).

## Локальный запуск и проверка

```sh
npm ci
npm run build:visuals
python3 serve.py --no-browser
```

Откройте `http://127.0.0.1:8000/`. После установки Chromium командой `npx playwright install chromium` выполните `npm test` и `npm run test:browser` при работающем сервере. Для проверки аккаунтов используйте отдельную тестовую базу и `npm run test:experience` по инструкции в [README.md](README.md). `npm run build` собирает статические файлы в `dist/`.
